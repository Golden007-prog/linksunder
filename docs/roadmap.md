# Roadmap and starter tasks

0.1 focuses on one trusted local user, one HTTP fault rule and CSS selectors.

Small, concrete contribution tasks:

- Add a JSON Schema export command and document it for editor autocomplete.
- Add a keyboard-accessible button to duplicate a scenario step, with a UI test.
- Add a localized date/time preference for report timestamps with unit coverage.
- Add Firefox support only after documenting unsupported network behaviors.

Future candidates: saved scenario library, retry steps, richer assertion types,
connection-level network policy, accessibility audit and configurable API statuses.
Accounts, payments, AI, cloud dashboards and extension ecosystems are out of scope.
