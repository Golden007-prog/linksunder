# Contributing

Use Node.js 24 LTS. Run `npm install`, `npm run setup`, and `npm run dev`.
Keep changes focused and document behavior. Run lint, typecheck, unit/integration
tests, E2E and build before opening a PR. Include a regression test for runner or
security changes and real screenshots for visible changes. Never commit `data/`,
credentials, reports from private sites, or personal scenario inputs.

Use clear commit messages and describe the problem, resulting behavior and checks.
Please discuss new dependencies or large features first. The first release favors
a small local workflow over cloud services. Starter tasks are in docs/roadmap.md.
