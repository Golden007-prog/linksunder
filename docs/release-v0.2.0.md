# LinkSunder v0.2.0 — desktop applications

Download, install and open LinkSunder. End users do not need Node.js, npm, Git or
terminal commands. The runtime, Playwright engine and Chromium are included.

- Windows x64: graphical installer and portable ZIP.
- Linux x64: DEB for compatible Ubuntu/Debian desktops and AppImage.
- Isolated application window, automatic local-engine lifecycle and report downloads.
- Offline/API failure/delay scenarios, real assertions, cancellation and persistent history.
- Save and reload scenarios without moving JSON files.

The included Broken/Fixed example is optional training; testing your own authorized
sites is fully available. There is no demo-only mode or trial feature limit.

No Android APK or iOS PWA is shipped. Desktop packages are unsigned. Linux library
and AppImage/FUSE compatibility depend on the distribution. HTTP routing is not a
hostile-site sandbox. Automated checks do not constitute full accessibility certification.
